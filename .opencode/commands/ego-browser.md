Load the ego-browser skill. Then use ego-browser to complete: $ARGUMENTS

Use the Bash tool to run ego-browser nodejs heredoc scripts. Start with `useOrCreateTaskSpace`, open pages with `openOrReuseTab`, observe with `snapshotText` and `captureScreenshot`, interact with `click`/`fillInput`/`typeText`/`pressKey`, and clean up with `completeTaskSpace`.
