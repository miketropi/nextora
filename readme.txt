== Description ==

Nextora is a modern WordPress block theme built for full-site editing. It combines the power of WordPress block templates and theme.json with the flexibility of Tailwind CSS v4, giving you a clean, scalable foundation for any project — from a simple blog to a full-featured business site.

**Key features:**

- **Full-site editing** — customize every part of your site with the WordPress Site Editor
- **Tailwind CSS v4** — utility-first CSS integrated with WordPress design tokens
- **Custom blocks** — header, hero section, post grid, image galleries, testimonials, CTAs, spotlight search, and more
- **WooCommerce ready** — built-in mini cart, store-aware header, and theme support
- **Responsive** — mobile-first design that looks great on every screen
- **Accessibility** — semantic HTML, ARIA labels, and keyboard navigation
- **Performance** — optimized CSS and JS pipelines with esbuild and PostCSS

== Installation ==

1. In your WordPress admin, go to **Appearance → Themes → Add New**.
2. Click **Upload Theme** and choose the `nextora.zip` file.
3. Click **Install Now** and then **Activate**.

Or install manually via FTP:

1. Unzip `nextora.zip` and upload the `nextora` folder to `/wp-content/themes/`.
2. Go to **Appearance → Themes** and activate Nextora.

**After activation:**

- Go to **Appearance → Editor** to customize templates and styles.
- The theme works out of the box — no configuration required.

== Frequently Asked Questions ==

= Does this theme work with the WordPress Site Editor? =

Yes. Nextora is a block theme built specifically for full-site editing. Edit every part of your site — header, footer, templates, and styles — through the Site Editor under **Appearance → Editor**.

= Is Nextora compatible with WooCommerce? =

Yes. Nextora includes built-in WooCommerce support: a store-aware header with a mini cart, product gallery styling, and theme support declared in `theme.json`.

= Can I use page builders like Elementor with Nextora? =

Yes. Nextora includes Elementor integration that loads the editor properly and separates core block assets from Elementor pages.

= Does Nextora support classic / non-block themes? =

No. Nextora is a block theme (FSE). It uses HTML block templates and `theme.json` instead of classic PHP templates (`header.php`, `single.php`, etc.).

= How do I customize colors and fonts? =

Use the **Styles** panel in the Site Editor (**Appearance → Editor → Styles**). Colors, typography, and spacing are defined in `theme.json` and synced with Tailwind CSS.

= How do I report a bug or request a feature? =

Please open an issue on the theme's GitHub repository or contact us at [https://beplusthemes.com/](https://beplusthemes.com/).
